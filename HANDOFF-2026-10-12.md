## Spot-check lab (step 5)

```
PIQ_VIDEO=<video> python -m cv.experiments.spotlab <tag> "<Windows out dir>" --per-type 30 --windows 2 --win-s 120
```

**Output paths:** pass a Windows path (`C:\...`). An MSYS path such as `/c/...` writes no webm.

**What it writes:**
- `questions.json`;
- `packs/pNNN.webm`: 10 clips per pack, each 2 s at 8 fps; S packs are 480x270, M packs 768x432;
- `ctx/aNNN.jpg`: 5x5 atlases of the whole frame.

**What each question type shows:**
- `lines`: a still frame repeated, which costs almost nothing to store.
- `ballmiss`: half a frame around the nearest ringed ball, with the tracker's rings drawn.
- Every other type: a crop around the thing asked about.

**Page:**
- Stage a site as:
  - `index.html`;
  - `sets.json` (`{"sets":[{"name","title"}]}`);
  - `sets/<name>/{questions.json,packs,ctx}`.
- Answers go to the db at `sets/<name>/answers/cNNN`: 100 questions per doc, `{a:{qid:{v,ms,at}}}`.
- Keys:
  - 1-4 answer, and "can't tell" is always the last option;
  - Z goes back one;
  - Space pauses;
  - S plays in slow motion.
- Sittings are 200 questions.
- Without `window.claude`, the page uses a frozen mock db (local preview).
- **Publish limits:** 64 MB and 255 files per publish, so publish large sets in parts to the same URL. 256 MB per version.

**Scoring:** only `sample == "random"` answers count. `model` holds the pipeline's answer:
- role: player, referee or other;
- team: A, B or unsure;
- yes/no types: the answer that means "the pipeline is right", which is yes for same, lines and ballring, and no for missing and ballmiss.
