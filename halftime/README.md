# halftime/

The three-minute read for the touchline at half time, made for a phone held
standing up. It leads with what a coach cannot see by watching: who is a
booking away from a red card, and who has run the whole half.

It reads the tag log and, when one has been published, the pipeline's
`cvStats/summary`. Run it with the rest of the site (`shared/README.md`,
"Local development"). It needs a coach account for the squad, and a match
link from the dashboard.
