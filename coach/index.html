Getting started

Four things to do once. This disappears when you're set up.

  1. Add your players
    Use the Roster tab. Each player needs their school email so they can see their own report.
  2. Invite them
    Press Invite next to each player. They sign in with Google and see only their own numbers.
  3. Create a match
    Just the opponent and the date. You can do this the morning of the game.
  4. Tag it on match day
    Open Live tagging on a tablet or phone. Whoever keeps the book can run it.
