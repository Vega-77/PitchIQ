Camera setup

Teach the software where the pitch is

A camera sees a flat picture. To measure how far a player ran, or how good a chance was, the software needs to know which part of that picture is which part of the field. You show it by clicking a few lines you can recognise — then it can work out the rest.

How it works

1

Take one still frame

A screenshot of the video works. Use a moment when you can see plenty of the field markings.

2

Click four or more spots

Corners, the halfway line, penalty box corners. Pick the list item first, then click that exact spot on the picture.

3

Check the yellow outline

A pitch outline appears over your photo. If it sits on the real painted lines, you're done.

Spread your clicks out. Four points bunched in one corner will look perfect and still be wrong everywhere else on the field. Corners at opposite ends are ideal.
The camera must not move. If it pans or zooms to follow the ball, one calibration cannot describe the whole video — you need a fixed, wide view.

Start

You set the field size on the next screen, and the page will try to measure it for you from the points you click.

Getting a frame from a video file

A screenshot is fine. If you'd rather pull an exact frame, run this from the project folder: 

python -m cv.experiments.grab_frame "match.mp4" --at 120

Then run the saved file through python -m cv.experiments.calibrate points.json once you've exported your clicks.

Click the highlighted spot

Pick a landmark from the list, then press and hold it on the picture — a magnifier opens so you can see the exact pixel.

Field size

 
Place five points and the page will try to measure the field for you.
Place eight points and the page will check whether the markings match the Laws.

Every distance and speed the software reports is scaled by these two numbers, so a guess that's 5m out makes every figure 5% wrong. The markings matter the same way: a school pitch painted with a tape and a guess is not wrong, but the software has to be told.

Accuracy

Place four points to see how good the fit is.
